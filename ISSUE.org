#+TITLE: Git-invariant audit: open issues
#+DATE: 2026-09-30

Invariant: OMP must behave the same with or without git, except for
git-specific features.

Scenarios: (A) no repository, (B) normal repository, (C) linked worktree,
(D) no =git= binary on PATH.

V1 (a linked worktree lost the main repo's =.git/info/exclude=) is fixed in
=crates/pi-walker/src/lib.rs= (=git_exclude_path=). The items below are open.

* TODO V2: ancestor =.gitignore= applies only when a repository exists  :walker:
- Where: =crates/pi-walker/src/lib.rs=, the parent ignore-state build. The
  test =collect_entries_ignores_parent_gitignore_above_non_repo_root= locks
  in this behavior on purpose.
- Repro (run): =proj/.gitignore= ignores =root-ign.txt=. The search root is
  =proj/src=. A shows the file. B hides it. This is true for =glob=, =grep=,
  =listWorkspace=, and =fuzzyFind=.
- Not affected: a =.gitignore= at or below the search root applies the same
  way in A and B (test =collect_entries_honors_gitignore_without_repo_marker=).
- Decision needed: without git, the walker has no stop point for ancestor
  =.gitignore= files. Choose between these options:
  1. Apply ancestor =.gitignore= files up to =$HOME=.
  2. Keep the current behavior as git's scope rule, and document it.

* TODO V5: the Hindsight memory bank uses the git root as its key  :state:
- Where: =packages/coding-agent/src/hindsight/bank.ts:77= uses
  =path.basename(vcs.repo(dir)?.primaryRoot() ?? dir)=.
- Effect [code-read, not run]: a subfolder of a repository shares the
  repository's bank, and a subfolder without git gets its own bank. A later
  =git init= above the folder moves it to a different bank. A key that is
  only the basename can make unrelated projects share one bank.
- Precedent: Mnemopi removed git-root keying for this reason (#2412,
  =packages/coding-agent/src/mnemopi/config.ts:193=). Mnemopi now keys by
  the resolved cwd plus a path hash.
- Decision needed: a cwd key (like Mnemopi) gives each worktree its own
  bank. The current key makes all worktrees share the main checkout's bank.
