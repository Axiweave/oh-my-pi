# Triage labels

| Canonical role | Local Status value | Meaning |
| --- | --- | --- |
| needs-triage | needs-triage | A maintainer must evaluate the work. |
| needs-info | needs-info | More information is required. |
| ready-for-agent | ready-for-agent | An agent can implement the specified work. |
| ready-for-human | ready-for-human | A human must implement the work. |
| wontfix | wontfix | The work will not proceed. |

MUST use these values for the Status fields described in `issue-tracker.md`.
These are local metadata values, not instructions to create GitHub labels.
